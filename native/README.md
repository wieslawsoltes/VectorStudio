# Optional native engines

The base app runs with `node server/local.mjs` without dependency installation. CDR conversion and native print additionally need system libraries/tools.

For Ubuntu/Debian development environments, install the development/runtime packages, then build:

```sh
sudo apt-get install g++ pkg-config libcdr-dev librevenge-dev inkscape ghostscript python3-pypdf
sh native/build.sh
```

A Linux x64 helper compiled against libcdr 0.1.7 and librevenge 0.0.5 is included. It dynamically links system libraries; those libraries are not bundled. The source is `cdr-pages.cpp`. Other operating systems/architectures should compile the helper against compatible libraries. Set `VELLUM_CDR_CONVERTER` to an explicit helper path if required.

The helper enumerates every SVG page generated by libcdr. The integration test uses the CC0 fixture in `tests/fixtures/`; that fixture has one page. Native CDR export is not available.

`print_pipeline.py` merges prepared pages, sets trim/bleed boxes, embeds the supplied printer ICC and invokes Ghostscript PDF/X generation. The command syntax is verified with Ghostscript 10.02.1. It writes a PDF and a structural-check report, always with `externalCertification: false`. Printer proofing and independent PDF/X certification remain external tasks. Solid process fills can enter the pipeline through the direct PDF path, which preserves exact CMYK operators such as pure K; unsupported process-fill effects are rejected.

`limit_exec.py` bounds native process address space, CPU and output file size. Requests have bounded input and child-process timeouts. This is resource containment, not an OS security sandbox. The native HTTP endpoints require the standalone server's authenticated identity boundary. They are intentionally unavailable in the Worker-hosted app.

Endpoints: `GET /api/native/capabilities`, `POST /api/native/cdr` (binary CDR body), `POST /api/native/print` (bounded JSON print job). Successful CDR response returns a Vellum document. Successful print response returns base64 PDF and its report.
